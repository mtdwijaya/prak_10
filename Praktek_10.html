Praktek Fragment & BottomNavigation

Membangun aplikasi Agenda Kuliah dengan tiga tab di bagian bawah, layar detail yang dibuka dari tab Tugas, dan tombol Back yang bekerja dengan benar.

1

Pengenalan & Tujuan Praktik

Pada praktik ini Anda membuat aplikasi Agenda Kuliah. Aplikasi memiliki tiga tab di bagian bawah: Jadwal, Tugas, dan Profil. Dari tab Tugas, pengguna dapat membuka layar detail sebuah tugas, lalu kembali dengan tombol Back.

Setelah selesai, Anda akan memahami cara membuat beberapa Fragment, memasangnya ke satu Activity, memilih tab lewat BottomNavigationView, dan mengirim data ke Fragment dengan arguments.

Prasyarat

Sudah membaca Teori 9 — Fragment dan BottomNavigation. Istilah seperti FragmentContainerView dan replace sudah dibahas di sana.

Hasil yang harus tampak

Aplikasi berjalan, tiga tab dapat dipilih, tombol tugas membuka detail, dan tombol Back kembali ke daftar tugas.

2

Target Tampilan

Target akhir berisi dua tab dan satu layar detail. Ukuran dan warna boleh berbeda, tetapi susunan elemen dan perilakunya harus sama.

Susunan Berkas Proyek

BerkasFungsi
MainActivity.ktActivity utama, memilih Fragment saat menu ditekan
JadwalFragment.kt, TugasFragment.kt, ProfilFragment.ktTiga tab di bagian bawah
DetailTugasFragment.ktLayar detail, menerima judul dan batas lewat arguments
activity_main.xml, bottom_nav_menu.xmlWadah Fragment dan daftar menu bawah
3

Persiapan Proyek & Dependensi

  1. Buka Android Studio, pilih New Project, lalu pilih template Empty Views Activity.
  2. Isi Name dengan Agenda Kuliah, Package name dengan com.example.agendakuliah, dan Language dengan Kotlin.
  3. Tunggu proyek selesai dibuka dan Gradle selesai disinkronkan.
  4. Buka app/build.gradle.kts (Module :app), lalu tambahkan dua dependensi berikut di dalam blok dependencies.
app/build.gradle.kts (Module :app)Gradle
dependencies {
    implementation("androidx.fragment:fragment-ktx:1.9.1")
    implementation("com.google.android.material:material:1.12.0")
}
  1. Klik Sync Now di bagian atas layar.
Perhatikan

Dependensi material adalah contoh versi. Periksa versi stabil terbaru di Maven sebelum dipakai, lalu sesuaikan angkanya.

  1. Buat kelas TugasFragment.kt. Perhatikan fungsi bukaDetail, yang menukar isi wadah dan menyimpan transaksi di back stack.
TugasFragment.ktKotlin
package com.example.agendakuliah

import android.os.Bundle
import android.view.View
import android.widget.Button
import androidx.fragment.app.Fragment

class TugasFragment : Fragment(R.layout.fragment_tugas) {

    override fun onViewCreated(view: View, savedInstanceState: Bundle?) {
        super.onViewCreated(view, savedInstanceState)

        view.findViewById<Button>(R.id.btnTugas1).setOnClickListener {
            bukaDetail("Laporan Fragment", "Jumat")
        }
        view.findViewById<Button>(R.id.btnTugas2).setOnClickListener {
            bukaDetail("Latihan BottomNav", "Senin")
        }
        view.findViewById<Button>(R.id.btnTugas3).setOnClickListener {
            bukaDetail("Kuis Retrofit", "Rabu")
        }
    }

    private fun bukaDetail(judul: String, batas: String) {
        parentFragmentManager.beginTransaction()
            .replace(R.id.fragmentContainer, DetailTugasFragment.newInstance(judul, batas))
            .addToBackStack("detail")
            .commit()
    }
}
Mengapa addToBackStack?

Tanpa baris ini, tombol Back langsung menutup aplikasi, bukan kembali ke daftar tugas. Nama "detail" hanya label untuk transaksi tersebut.

DetailTugasFragment.ktKotlin
package com.example.agendakuliah

import android.os.Bundle
import android.view.View
import android.widget.Button
import android.widget.TextView
import androidx.fragment.app.Fragment

class DetailTugasFragment : Fragment(R.layout.fragment_detail_tugas) {

    companion object {
        private const val ARG_JUDUL = "judul"
        private const val ARG_BATAS = "batas"

        fun newInstance(judul: String, batas: String) = DetailTugasFragment().apply {
            arguments = Bundle().apply {
                putString(ARG_JUDUL, judul)
                putString(ARG_BATAS, batas)
            }
        }
    }

    override fun onViewCreated(view: View, savedInstanceState: Bundle?) {
        super.onViewCreated(view, savedInstanceState)

        val judul = arguments?.getString(ARG_JUDUL).orEmpty()
        val batas = arguments?.getString(ARG_BATAS).orEmpty()

        view.findViewById<TextView>(R.id.tvJudulDetail).text = judul
        view.findViewById<TextView>(R.id.tvBatasDetail).text = "Batas: $batas"

        view.findViewById<Button>(R.id.btnKembali).setOnClickListener {
            parentFragmentManager.popBackStack()
        }
    }
}
Jangan menyimpan data di konstruktor

Fragment dapat dibuat ulang oleh sistem, dan konstruktor yang berisi parameter akan hilang saat itu terjadi. Simpan data di arguments seperti pada kode di atas.

8

Menghubungkan Semua di MainActivity

MainActivity menghubungkan menu bawah dengan Fragment. Ada dua hal penting: layar pertama hanya dipasang saat Activity baru dibuka, dan setiap pindah tab menutup layar detail yang masih tersimpan.

  1. Buka MainActivity.kt, lalu ganti seluruh isinya dengan kode berikut.
MainActivity.ktKotlin
package com.example.agendakuliah

import android.os.Bundle
import androidx.appcompat.app.AppCompatActivity
import androidx.fragment.app.Fragment
import androidx.fragment.app.FragmentManager
import com.google.android.material.bottomnavigation.BottomNavigationView

class MainActivity : AppCompatActivity() {

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)

        val bottomNav = findViewById<BottomNavigationView>(R.id.bottomNav)

        if (savedInstanceState == null) {
            gantiFragment(JadwalFragment())
        }

        bottomNav.setOnItemSelectedListener { item ->
            val fragment: Fragment = when (item.itemId) {
                R.id.menu_jadwal -> JadwalFragment()
                R.id.menu_tugas -> TugasFragment()
                R.id.menu_profil -> ProfilFragment()
                else -> return@setOnItemSelectedListener false
            }
            // Tutup layar detail yang masih tersimpan, lalu pindah tab.
            supportFragmentManager.popBackStack(null, FragmentManager.POP_BACK_STACK_INCLUSIVE)
            gantiFragment(fragment)
            true
        }
    }

    private fun gantiFragment(fragment: Fragment) {
        supportFragmentManager.beginTransaction()
            .replace(R.id.fragmentContainer, fragment)
            .commit()
    }
}
  1. Pastikan semua berkas di atas berada di package com.example.agendakuliah, lalu klik Build > Make Project.
Mengapa savedInstanceState == null?

Saat layar diputar, Activity dibuat ulang. Pengecekan ini mencegah tab pertama dipasang lagi dan menimpa tab yang sedang tampil.

9

Menjalankan & Menguji Hasil

Jalankan aplikasi di emulator atau HP. Lakukan urutan berikut, lalu bandingkan dengan target di bagian 2.

  1. Tab Jadwal terbuka pertama, dengan dua jadwal kuliah.
  2. Tekan ikon Tugas. Tiga tombol tugas tampil.
  3. Tekan Laporan Fragment. Layar detail menampilkan judul Laporan Fragment dan Batas: Jumat.
  4. Tekan tombol Back di perangkat. Daftar tugas kembali tampil, bukan keluar aplikasi.
  5. Tekan Kuis Retrofit, lalu tekan ikon Profil. Layar Profil tampil dan tidak ada layar detail yang tertinggal.
  6. Tekan Back. Aplikasi keluar, karena tidak ada lagi transaksi di back stack.
10

Memahami Back Stack

Setiap commit() dengan addToBackStack menyimpan satu langkah yang bisa dibatalkan. Tombol Back membatalkan langkah terakhir.

Aksi penggunaTransaksiMasuk back stack?
Membuka Jadwal saat aplikasi dibukareplace JadwalFragmentTidak
Menekan tab TugaspopBackStack, lalu replace TugasFragmentTidak
Menekan tugas di daftarreplace DetailTugasFragmentYa, dengan nama detail
Tombol Back atau Kembali di detailpopBackStackLangkah detail dihapus
Catatan

Tab tidak masuk back stack, sehingga Back dari tab pertama langsung menutup aplikasi. Ini sesuai pola BottomNavigation: menu bawah memindahkan tujuan, bukan menambah riwayat.

12

Rangkuman & Langkah Lanjutan

  • Fragment dipasang ke FragmentContainerView lewat replace.
  • BottomNavigationView memilih Fragment berdasarkan item.itemId.
  • Data dikirim ke Fragment lewat arguments melalui fungsi newInstance.
  • addToBackStack membuat tombol Back kembali ke layar sebelumnya.
  • Tab dibersihkan dari back stack saat berpindah, agar Back tidak kembali ke layar detail yang sudah tertutup.

Langkah Lanjutan (opsional)

  • Ganti tombol dengan daftar: gunakan RecyclerView (lihat Praktek 11) agar daftar tugas bisa berisi banyak item.
  • Navigation Component: pelajari cara mengatur perpindahan Fragment dengan navigation graph, seperti dibahas di Teori 9 bagian lanjutan.
  • Simpan status tugas: gunakan ViewModel agar status tugas tidak hilang saat Fragment dibuat ulang.
