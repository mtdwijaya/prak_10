Praktek Google Maps & GPS

Membangun aplikasi Lokasi Saya: meminta izin lokasi, mengambil posisi perangkat lewat GPS, lalu menampilkan pin di Google Maps.

1

Pengenalan & Tujuan Praktik

Pada praktik ini Anda membuat aplikasi Lokasi Saya. Aplikasi meminta izin lokasi, mengambil posisi perangkat lewat GPS, lalu menampilkan pin merah di peta Google Maps tepat di posisi tersebut.

Setelah selesai, Anda akan memahami cara mengaktifkan Maps SDK, memasang kunci API dengan aman, menampilkan peta lewat SupportMapFragment, dan menaruh marker dari data GPS.

Prasyarat

Sudah membaca Teori 10 — Penggunaan GPS di Android. Istilah seperti FusedLocationProviderClient dan runtime permission sudah dibahas di sana.

Perlu akun Google Cloud

Maps SDK memakai kunci API dari Google Cloud Console. Langkah pendaftaran dan penagihan dijelaskan di bagian 3.

3

Persiapan Google Cloud & API Key

Google Maps SDK membutuhkan kunci API dari Google Cloud. Langkah ini dilakukan sekali di browser.

  1. Buka console.cloud.google.com dan login dengan akun Google Anda.
  2. Buat project baru, misalnya dengan nama LokasiSaya, lalu pastikan project tersebut yang aktif.
  3. Buka menu APIs & Services > Library, cari Maps SDK for Android, lalu klik Enable.
  4. Buka APIs & Services > Credentials, pilih Create credentials > API key.
  5. Salin kunci yang muncul. Anda akan memasukkannya ke local.properties pada bagian berikut.
Penagihan (billing)

Google Maps Platform memerlukan akun penagihan aktif agar kunci API dapat dipakai. Periksa ketentuan dan kuota terbaru di Google Cloud Console sebelum membuat aplikasi publik.

4

Dependensi & Kunci di Gradle

Ada dua hal yang ditambahkan di Gradle. Dependensi memasang library, dan manifestPlaceholders menyalin kunci API dari local.properties ke manifest.

  1. Buka local.properties di root proyek, lalu tambahkan satu baris berikut. Ganti isinya dengan kunci API Anda.
local.propertiesProperties
MAPS_API_KEY=ISI_KUNCI_API_ANDA
  1. Buka app/build.gradle.kts (Module :app), lalu ganti isinya dengan kode berikut. Jika file sudah berisi plugins dan android, pertahankan bagian tersebut dan tambahkan hanya bagian yang ditandai.
app/build.gradle.kts (Module :app)Gradle
import java.util.Properties

// build.gradle.kts (Module :app)
val localProps = Properties().apply {
    val file = rootProject.file("local.properties")
    if (file.exists()) load(file.inputStream())
}

android {
    defaultConfig {
        manifestPlaceholders["MAPS_API_KEY"] = localProps.getProperty("MAPS_API_KEY", "")
    }
}

dependencies {
    implementation("com.google.android.gms:play-services-maps:20.1.0")
    implementation("com.google.android.gms:play-services-location:21.4.0")
}
  1. Klik Sync Now.
Mengapa tidak langsung di manifest?

File local.properties biasanya sudah diabaikan oleh Git di proyek Android. Dengan begitu, kunci API tidak ikut terunggah saat Anda membagikan kode.

5

AndroidManifest.xml

Manifest menyatakan izin yang diminta aplikasi dan meta-data kunci API yang dibaca Google Maps saat peta dibuka.

  1. Buka app/src/main/AndroidManifest.xml, lalu ganti isinya dengan kode berikut. Jika ada tag <activity> lain, pertahankan.
app/src/main/AndroidManifest.xmlXML
<?xml version="1.0" encoding="utf-8"?>
<manifest xmlns:android="http://schemas.android.com/apk/res/android">

    <!-- Izin lokasi, ditaruh di luar tag application -->
    <uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
    <uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION" />
    <uses-permission android:name="android.permission.INTERNET" />

    <application
        android:allowBackup="true"
        android:label="@string/app_name"
        android:theme="@style/Theme.LokasiSaya">

        <!-- Kunci API Google Maps, diisi otomatis dari local.properties -->
        <meta-data
            android:name="com.google.android.geo.API_KEY"
            android:value="${MAPS_API_KEY}" />

        <activity
            android:name=".MainActivity"
            android:exported="true">
            <intent-filter>
                <action android:name="android.intent.action.MAIN" />
                <category android:name="android.intent.category.LAUNCHER" />
            </intent-filter>
        </activity>

    </application>

</manifest>
Perhatikan

Meta-data kunci API harus berada di dalam <application>. Izin harus berada di luar tag tersebut.

Layout Peta

Peta ditaruh dengan tag fragment. Tag ini memuat SupportMapFragment, yang mengurus tampilan peta di dalamnya.

  1. Buka res/layout/activity_main.xml, lalu ganti isinya dengan kode berikut.
res/layout/activity_main.xmlXML
<?xml version="1.0" encoding="utf-8"?>
<LinearLayout xmlns:android="http://schemas.android.com/apk/res/android"
    android:layout_width="match_parent"
    android:layout_height="match_parent"
    android:orientation="vertical">

    <fragment
        android:id="@+id/map"
        android:name="com.google.android.gms.maps.SupportMapFragment"
        android:layout_width="match_parent"
        android:layout_height="0dp"
        android:layout_weight="1" />

    <TextView
        android:id="@+id/tvStatus"
        android:layout_width="match_parent"
        android:layout_height="wrap_content"
        android:padding="16dp"
        android:text="Menunggu lokasi..."
        android:textSize="16sp" />

</LinearLayout>
7

Menulis MainActivity

MainActivity mengerjakan empat hal: meminta izin, mengambil lokasi, menunggu peta siap, lalu memasang pin. Ada dua urutan yang bisa terjadi, yaitu peta siap lebih dulu atau lokasi lebih dulu. Kode di bawah menangani keduanya.

  1. Buka MainActivity.kt, lalu ganti isinya dengan kode berikut.
MainActivity.ktKotlin
package com.example.lokasisaya

import android.Manifest
import android.annotation.SuppressLint
import android.content.pm.PackageManager
import android.location.Location
import android.os.Bundle
import android.widget.TextView
import androidx.activity.result.contract.ActivityResultContracts
import androidx.appcompat.app.AppCompatActivity
import androidx.core.content.ContextCompat
import com.google.android.gms.location.LocationServices
import com.google.android.gms.location.Priority
import com.google.android.gms.maps.CameraUpdateFactory
import com.google.android.gms.maps.GoogleMap
import com.google.android.gms.maps.OnMapReadyCallback
import com.google.android.gms.maps.SupportMapFragment
import com.google.android.gms.maps.model.LatLng
import com.google.android.gms.maps.model.MarkerOptions
import com.google.android.gms.tasks.CancellationTokenSource

class MainActivity : AppCompatActivity(), OnMapReadyCallback {

    private var peta: GoogleMap? = null
    private var lokasi: Location? = null
    private lateinit var tvStatus: TextView

    private val mintaIzin = registerForActivityResult(
        ActivityResultContracts.RequestMultiplePermissions()
    ) { hasil ->
        if (hasil.values.any { it }) {
            ambilLokasi()
        } else {
            tvStatus.text = "Izin lokasi ditolak"
        }
    }

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)

        tvStatus = findViewById(R.id.tvStatus)

        val fragmentPeta = supportFragmentManager.findFragmentById(R.id.map) as SupportMapFragment
        fragmentPeta.getMapAsync(this)

        if (izinDiberikan()) {
            ambilLokasi()
        } else {
            mintaIzin.launch(
                arrayOf(
                    Manifest.permission.ACCESS_FINE_LOCATION,
                    Manifest.permission.ACCESS_COARSE_LOCATION
                )
            )
        }
    }

    override fun onMapReady(googleMap: GoogleMap) {
        peta = googleMap
        // Jika lokasi sudah didapat sebelum peta siap, pasang pin sekarang.
        lokasi?.let { tampilkanPin(it) }
    }

    @SuppressLint("MissingPermission")
    private fun ambilLokasi() {
        val fused = LocationServices.getFusedLocationProviderClient(this)
        fused.getCurrentLocation(Priority.PRIORITY_HIGH_ACCURACY, CancellationTokenSource().token)
            .addOnSuccessListener { hasil: Location? ->
                if (hasil != null) {
                    lokasi = hasil
                    tampilkanPin(hasil)
                } else {
                    tvStatus.text = "Lokasi belum tersedia. Pastikan GPS aktif."
                }
            }
    }

    private fun tampilkanPin(loc: Location) {
        val map = peta ?: return
        val posisi = LatLng(loc.latitude, loc.longitude)

        map.clear()
        map.addMarker(MarkerOptions().position(posisi).title("Lokasi Saya"))
        map.moveCamera(CameraUpdateFactory.newLatLngZoom(posisi, 16f))

        tvStatus.text = "Lat %.6f, Lon %.6f".format(loc.latitude, loc.longitude)
    }

    private fun izinDiberikan(): Boolean {
        return ContextCompat.checkSelfPermission(this, Manifest.permission.ACCESS_FINE_LOCATION) ==
                PackageManager.PERMISSION_GRANTED ||
                ContextCompat.checkSelfPermission(this, Manifest.permission.ACCESS_COARSE_LOCATION) ==
                PackageManager.PERMISSION_GRANTED
    }
}
Mengapa dua urutan?

Peta dan lokasi berjalan bersamaan. Jika onMapReady dipanggil lebih dulu, pin dipasang saat lokasi tiba. Jika lokasi tiba lebih dulu, pin dipasang saat peta siap.

Mengapa getCurrentLocation?

Fungsi ini meminta satu kali pembacaan lokasi yang akurat, lalu selesai. Cocok untuk pin statis. Untuk pelacakan terus-menerus, gunakan requestLocationUpdates seperti di Teori 10.

8

Menjalankan & Menguji

Gunakan emulator dengan image yang memiliki Google Play, karena Maps SDK membutuhkan Google Play services. Atur lokasi emulator dari menu Extended controls > Location sebelum menjalankan aplikasi.

  1. Klik Run dan pilih emulator.
  2. Saat aplikasi pertama dibuka, dialog izin lokasi muncul. Pilih While using the app atau Allow.
  3. Peta terbuka dan teks status menampilkan koordinat. Pin merah berada di tengah peta.
  4. Ketuk pin, lalu jendela kecil bertuliskan Lokasi Saya muncul.
  5. Tutup aplikasi, ubah lokasi di Extended controls, lalu buka lagi. Pin berpindah ke lokasi baru.
  6. Tolak izin lewat pengaturan aplikasi. Teks status menampilkan Izin lokasi ditolak.

Mengubah Tampilan Pin

Marker bisa diberi judul, deskripsi, dan warna. Potongan berikut menggantikan pemanggilan addMarker di fungsi tampilkanPin.

  1. Ganti baris map.addMarker(...) dengan kode berikut. Tambahkan import yang dibutuhkan di bagian atas file.
MainActivity.kt (fungsi tampilkanPin)Kotlin
// Ganti warna pin menjadi biru
import com.google.android.gms.maps.model.BitmapDescriptorFactory

map.addMarker(
    MarkerOptions()
        .position(posisi)
        .title("Lokasi Saya")
        .snippet("Anda berada di sini")
        .icon(BitmapDescriptorFactory.defaultMarker(BitmapDescriptorFactory.HUE_AZURE))
)
Warna lain

Pilihan warna yang tersedia adalah konstanta BitmapDescriptorFactory.HUE_*, misalnya HUE_RED, HUE_GREEN, atau HUE_AZURE.

Menjaga Kunci API

Kunci API yang bocor bisa dipakai orang lain dan menimbulkan tagihan. Beberapa kebiasaan berikut membantu menjaganya.

  • Simpan kunci di local.properties, jangan langsung di kode atau manifest.
  • Batasi kunci hanya untuk Android apps dengan package name aplikasi Anda.
  • Batasi kunci hanya untuk Maps SDK for Android, agar tidak bisa dipakai untuk API lain.
  • Jika kunci terlanjur terunggah ke repositori publik, buat kunci baru dan hapus yang lama.
12

Rangkuman & Langkah Lanjutan

  • Maps SDK memerlukan kunci API dari Google Cloud dan library play-services-maps.
  • Kunci disimpan di local.properties dan disalin ke manifest lewat manifestPlaceholders.
  • Peta ditampilkan dengan SupportMapFragment, dan getMapAsync menghasilkan GoogleMap setelah siap.
  • Lokasi GPS diambil dengan Fused Location Provider, lalu dipasang sebagai marker di koordinat tersebut.

Langkah Lanjutan (opsional)

  • Pelacakan langsung: ganti getCurrentLocation dengan requestLocationUpdates agar pin bergerak mengikuti perangkat.
  • Rute: tambahkan dua marker, lalu gambar garis dengan Polyline.
  • Compose: pelajari library maps-compose jika proyek Anda memakai Jetpack Compose.
